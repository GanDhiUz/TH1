# 모바일 가독성 리디자인: 확정된 의도

확정일: 2026-11-23 (요청자: 겨울잠)

## 목표 (Why)
휴대폰에서 글씨가 작아 읽기 힘든 문제를 없애, 학생이 확대하지 않고도 편하게 읽게 한다.
현재 문제: "한 장 핵심 정리"는 넓은 SVG 포스터를 폰 폭으로 축소해 글씨가 5~6px까지 작아지고,
모션 그래픽은 자막 상자가 좁아 한 줄에 5~6글자씩 끊기며, 오른쪽 아래 검은 플로팅 버튼이 글자를 가린다.

## 대상 (Who)
휴대폰으로 혼자 복습하는 중학교 1학년 학생 (기술·가정 2학기).

## 범위
- 목차 지도, 하위 단원 선택 창
- 수업 패키지 3종: 교육용 모션 그래픽, 한 장 핵심 정리, 인터랙티브 학습지
- 휴대폰 화면에서는 배치를 새로 짠다 (예: 3열 카드 → 위에서 아래로 한 줄씩 쌓기)
- 디자인 방향: frontend-design 원칙(완성도 높고 개성 있는 UI)

## 성공 기준 (Success)
- 휴대폰(폭 360~430px)에서 본문 글씨 최소 16px
- 핀치 줌 없이 읽힘, 가로 스크롤 없음
- 글자를 가리는 요소 없음 (오른쪽 아래 검은 버튼 등)
- PC·태블릿 화면은 지금과 똑같이 보임

## 제약 (Constraint)
- index.html을 직접 고치지 않는다. index.html을 복사한 새 파일(예: index-mobile.html)에 작업한다.
- 요청자가 새 버전을 확인하고 문제가 없으면, 그때 원본 index.html에 반영해도 된다 (요청자 승인 완료).

## 하지 않을 것 (Out of scope)
- 학습 내용(글, 문제, 정답)과 순서 변경
- 내레이션·효과음 등 기능 변경
- PC·태블릿 디자인 변경
- 새 단원이나 새 기능 추가
